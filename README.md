# PyExeParser

Инструмент на Python для разбора PE/MZ-файлов: заголовки, секции, таблица импортов
и анализ машинного кода. Разбирает исполняемый файл по спецификации — без запуска
самого файла и без готовых парсеров.

## Стек

- Python 3.12
- `struct` для разбора бинарных заголовков
- `capstone` для дизассемблирования x86-64
- `pytest` для тестов

## Что умеет

- Определяет формат: MZ (DOS) или PE (Windows).
- Парсит PE32 и PE32+ (32/64 бита).
- Читает заголовки, секции и их атрибуты.
- Разбирает таблицу импортов: какие DLL и функции использует файл.
- Сохраняет машинный код секций в `.bin`.
- Анализирует машинный код:
  - ищет байтовые паттерны;
  - находит ASCII-строки;
  - считает частые байты;
  - дизассемблирует через Capstone и сохраняет `.asm`.
- Пишет лог разбора в файл.
- Тесты на реальных `calc.exe` и `notepad.exe`: количество секций и импортов.

## Структура

```
parsers/                  MZ, PE, импорты, точка входа
infrastructure/           константы, ошибки, секции, логи, машинный код
machine_code_analyzer/    поиск паттернов, строк, дизассемблирование
exe_files/                тестовые бинарники
tests/                    pytest
main.py                   CLI
```

## Как запустить

```bash
pip install -r requirements
python main.py
```

Ввести путь к файлу:

```
Введите файл для проверки: exe_files/notepad.exe
```

Результат: информация в консоли, логи и сгенерированные `.bin`/`.asm` в папке output.

## Тесты

```bash
pytest
```

## Область применения

- Только x86/x86-64, без ARM.
- Нет полного разбора ресурсов и подписей.
- Сознательно не претендует на замену `pefile`, `dumpbin` или IDA: задача была
  разобрать формат руками, а не обернуть готовую библиотеку.

## Чему научился

- Читать бинарный формат по спецификации, а не через готовую библиотеку.
- Работать с `struct`, смещениями и выравниванием.
- Понимать, как ОС загружает PE-файл: заголовки, секции, импорты, RVA.
- Писать тесты на бинарных данных.
